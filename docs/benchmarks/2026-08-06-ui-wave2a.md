## 1. The measurement bug that came first

`tests/conftest.py` never set `QT_QPA_FONTDIR`. Qt's offscreen plugin ships no
font database, so every glyph in every GUI test was a tofu box of the wrong
width — and the wave-1 height gates were measuring those boxes. `tools/shots.py`
had always set it, which is why the screenshots looked right while the numbers
did not.

| populated Compress page, 910×512 | tofu | real fonts |
|---|---|---|
| before wave 2a | — | **869 px** |
| after wave 2a  | 669 px | **748 px** |

The 80px gap is the whole reason this is recorded: every budget claim in
research/23 §1–§2.4 was checked against the left-hand column. conftest now sets
the font directory, and the two numbers agree with `tools/shots.py` for the
first time.

## 4. W2-8 on the tree it was written for

The whole `Programs` folder, external HDD, analysis only (nothing written):

| | fixed tick of 5 | adaptive tick |
|---|---|---|
| files found | 42 | 42 |
| progress emissions | 10 | 43 |
| **longest silence** | **4.7 s** | **0.3 s** |
| median gap | 1.47 s | 0.19 s |
| distinct card states | 10 | 27 |

Before W2-8 the entire scan was a single frozen card. The fixed tick of 5 was
the first implementation and still left a 4.7 s freeze on the big installers,
so the tick is now `max(1, total // 200)`: every file for small trees, still
only ~200 signals for a 10k-file one.

(Wall-clock for the scan was 18.6 s then 7.4 s — again cache warmth between
the two runs, not the tick change. The silence numbers are the ones that mean
something.)
